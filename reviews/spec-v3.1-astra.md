### Three small fixes before spend

1. **Make the geometric gate conservative about ties** (§§4–5, lines 194–200, 252–261). Suppose a model picks 64 occurrences of exactly the same token, and its text-only adversary ties all 1,024 occurrences. Every model neighbour is a valid adversary neighbour. Yet the expected overlap fraction is only \(64/1024=0.0625\), easily passing the “different from adversary” threshold of 0.5. Two identical tied distance rows can likewise appear novel relative to one another. **Keep expected overlap as a descriptive statistic; for selection, require the maximum overlap compatible with the cutoff ties to be ≤0.5, or mark a threshold-straddling case indeterminate.** Add this exact counterexample to the pre-A tests. The “least intervention first” ordering is otherwise a reasonable declared preference; specify how the maximum is aggregated across sites/models and give a final deterministic tiebreak.

2. **Fix the stitched baseline’s denominator** (§5D, lines 239–242). For fixed \(i\) and signed lag \(\Delta=j-i\), there is exactly one position at that lag from \(i\): \(j\). Its same-source indicator *is the observation*, so observed minus baseline is identically zero. Instead, for each observed \(\Delta\), average \(1[s(u)=s(u+\Delta)]\) over **all valid query positions \(u\)** in that stitched schedule, then average those baseline values over the observed neighbour lags. Test a case where observed and baseline genuinely differ.

3. **Make the independent audit replay data that actually exist** (§3, lines 137–143; §12.4, lines 495–503). Q contains 64 of each text’s 512 suffix positions; the separate audit draw is from all 512. Only about **4 of 32** audit queries are expected to have production matches and suffix-screen records. Draw one audit query per text **from its 64 suffix queries in Q**, using the independent seed. Time one complete explicit-lag audit row in the pilot and scale that measurement; if necessary, audit fewer full rows, retaining both models and all masks. Reserve the completion audit **before** dispatching optional census work, including billable startup and retries. This protects both the dollar cap and the promise of a verified result.
