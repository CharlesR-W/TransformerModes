**Corrections before stage (i):**

1. **Make the exhaustive fixture executable** (§10, lines 297–299). With \(N=6,L=2\), there are only **five** mean-zero site directions and **ten** spatial through-depth modes. The production eight-gap scale, 16-mode \(E,\Delta\), and 16/17 cutoff cannot be evaluated. Keep all 720 permutations, but specify a toy scale rank and cutoff, e.g. \(r=2,K=2\), using direct dense spectra and an isolated boundary. For the count, rank the **leading eigenvalue** and test its exceedance rule; the count itself has no separately specified p-value. For K5, define “rank 1” with the same conservative energy-tie rule used in production.
2. **Fix the scale definition and solver handoff** (§7, lines 183–191). Use the **eight smallest gaps**—\(1-\lambda_k\) for the eight *largest nonconstant eigenvalues*—not the “8 largest … gaps.” The shift is correct for selecting those eigenvalues. But `/home/ubuntu/code/TransformerModes/exp1/spacetime.py:174–186` expects an **unshifted, constant-first** decomposition and then slices off column zero. Passing the sorted shifted decomposition would discard the leading nonconstant direction and retain the constant. Pass the original past walks to `balance_direct`, or explicitly restore the constant-first eigenpair before handing over a cached decomposition. Test on a nonflat fixture with a unique leading direction; the flat fixture can conceal this bug.
